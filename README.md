# CLI Task Manager

A command-line task management application developed in Python.

## Features

- Add and view tasks
- Mark tasks as completed
- Delete tasks
- View completed tasks separately
- Save and load tasks using JSON
- Handle invalid menu selections and task inputs

## Technologies

- Python 3
- JSON for local data persistence
- Git and GitHub for version control

## Getting Started

Clone the repository and navigate to its directory.

Run the application using:

`python3 main.py`

Follow the interactive menu to manage your tasks.

Task data is stored locally in `tasks.json`, which is created when tasks are saved.
